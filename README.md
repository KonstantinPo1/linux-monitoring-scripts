# linux-monitoring-scripts
Simple Linux monitoring and troubleshooting scripts for infrastructure practice.
## Current scripts

### system_check.sh
Basic system diagnostic script that displays:

- System uptime
- CPU and memory usage
- Disk usage
- Network connections
- Failed services
- Recent logins
